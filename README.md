# QuizArena

Full-stack online quiz and assessment platform featuring dedicated interfaces for teachers and students. Teachers can create, configure, and publish timed tests with single-choice, multiple-choice, and true/false questions, view real-time student attempt submissions, export grades to CSV, and analyze test performance with interactive analytics. Students join tests securely via access codes, complete tests with autosaved progress, navigated question palettes, and anti-cheating tab-switch detection, and review their detailed performance upon result publication.
